# Reports
This folder contains the Jasper Reports project file. Defined in the file is the Bill Number Status report which display a summary report of the count of forms grouped by status. You will need to install [Jaspersoft Studio 6.21.3](https://community.jaspersoft.com/download-jaspersoft/community-edition/) to open the file.

**NOTE: The copy of Bill_Number_Status.jrxml in opoppr/src/main/jasperreports is the version of the report that is built and shipped with the application.**
